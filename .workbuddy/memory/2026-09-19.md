## 产品定位与工作流梳理（OpsArk 智能运维）

- 阅读 `需求.md`、`README.md`、`docs/INTELLIGENT_REQUIREMENT_PROCESSING_FLOW.md`、`docs/用户体系与云能力实施方案-2026-09-17.md`，梳理出平台定位、工作流、人群、痛点、亮点。
- 产出：`docs/OpsArk产品定位与工作流.html`（一页纸，含定位边界、用户五步/系统十步闭环、三条护栏、5 类人群分级、9 条痛点→解法、5 大卖点、3 个主推场景、5 条对外承诺红线）。
- 定位结论（后续物料沿用）：**不卖"AI 懂运维"，卖"做完 + 验完 + 记完"的执行闭环**。三句话差异化 = 真执行（独立 Agent 沙箱终端）/ 真校验（独立只读后置校验 + 整体目标门禁）/ 凭据不出本机 + 全链路审计。
- 主推 Slogan：`一句话，把运维做完。`
- 目标人群优先级：P0 = 兼运维的后端开发、中小团队 IT/系统管理员；P1 = 代运维服务商、运维新人；P2 = 研发临时环境操作。
- 主推场景收敛为三个：日常巡检/健康检查、故障排查/诊断、部署上线。
- 已提示红线：大文件分片、断点恢复、SQLite 持久化尚未完成，对外物料不得承诺。
