# Core 界面国际化、下拉框与主题统一

## 范围与原则

本次保留现有 Vue / Pinia / vue-i18n 结构及六套主题，在现有设计上修补缺口，不改写任务执行协议、凭据存储方式或模型生成内容。

- 界面语言：覆盖服务器、日志、敏感信息、模型、工具、Skill、设置、工作台、文件编辑与终端界面的固定文案、提示及常见系统状态。
- 下拉框：页面中的原生 `select` 统一使用 `ParameterSelect`；技术参数仍提交原始枚举值，不提交翻译后的标签。
- 主题：保留 carbon、midnight、graphite、plum、porcelain、mist，统一状态色、弹层、表单和终端主题变量。

## 主要修复

### 中英文切换

- 补齐敏感信息、知识上传/设置、文件与终端等界面的固定中文、占位提示、按钮辅助名称。
- 文件时间按当前界面语言格式化；界面提示采用响应式翻译，避免操作发生时的语言一直残留。
- 新增 `src/features/preferences/coreText.ts`，仅在展示层翻译已知的 Core 连接、模型可用性、表单校验和部分任务状态提示。未识别的底层错误继续展示原文，以保留排错信息。
- 中英文资源键保持对齐；新增切换语言和组件交互回归测试。

### 下拉框

- 服务器分组、日志筛选、敏感信息服务器、Agent 模型/权限、Skill 分类、知识库、文件换行符与高级模型参数使用同一组件。
- 统一边框、选中态、悬停态、字号和焦点环，随六套主题切换。
- 弹层脱离滚动容器裁剪，计算视口边界与向上/向下展开位置。
- 支持方向键、Home/End、Enter/Space、Escape、Tab、点击外部关闭和焦点回归。
- 保留禁用选项、禁用 fieldset、必填/可选清空以及真实 value 提交语义。

### 六套主题

- 补齐语义色、遮罩和阴影变量，移除亮色界面中的固定深色底板。
- 提升弱提示文字对比度，统一成功、警告、错误与信息状态色。
- Shell、本地终端、Agent 终端共用完整 ANSI 配色和字体偏好读取逻辑。
- 外观面板补齐语言/主题选中状态、键盘 Escape 和焦点返回；偏好写入失败不阻止本次切换。

## 验证范围

- 独立 Chromium 测试上下文，使用虚构服务器和模型；不读取真实浏览器数据，也不连接真实 SSH 或模型服务。
- 六套主题 × 两种语言，覆盖七个管理页面（84 次路由访问）、下拉弹层边界、模型抽屉键盘选择以及工作台连接遮罩。
- 类型检查、前端生产构建、组件测试与全量 Vitest 回归。
- 最终回归（2026-09-17）：`npm test` 共 130 个测试文件通过，1301 项通过、16 项跳过；`npm run check`、`npm run build` 和 `git diff --check` 均通过。
- 额外验证底部 Agent 菜单向上展开、方向键跳过不可用模型、工作台和本地终端提示即时切换语言。
- 自动化对比度测试：六套主题弱提示文字在背景、面板和浮层上均不低于 4.5:1；终端正文不低于 7:1，除 ANSI 黑色外的终端调色板文字不低于 4.5:1。这是指定色板组合的检查，不等同于全产品无障碍认证。
- 生产预览确认设置入口隐藏、`/settings` 重定向，以及 `Opsark Agent` 标题和开发功能限制保持不变。
- Vite 构建成功，但仍提示部分 chunk 大于 500 kB；包体拆分不在此次界面整改范围。

## 保留边界

- 用户输入、模型回答、Shell 原始输出、历史业务日志和可编辑的工具/Skill 内容不因界面切换而被改写。
- 外部服务返回的未知错误可能保留原语言；已知 Core 提示由展示层转换。
- 操作系统/浏览器绘制的原生日期选择器、文件选择窗口等内部文字由宿主系统决定。
- 工作区操作、终端操作、文件右键和任务列表属于命令菜单，保留原有交互形态；本次 `ParameterSelect` 的键盘行为规范不代表这些命令菜单的完整无障碍整改，部分菜单仍可补充方向键与焦点管理。
- 浏览器验证覆盖前端样式与交互，不替代 Tauri 桌面端真实 SSH、本地 PTY 与系统钥匙串集成验收。
- 先前的生产限制保持不变：设置入口和任务日志上传仅开发环境显示；生产 `/settings` 路由回到首页；名称仍为 `Opsark Agent`。
