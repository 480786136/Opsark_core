# 个人 Skill 自动同步（2026-09-17）

## 需求与实现边界

登录/恢复登录后立即同步个人 Skill；新增、有效编辑和确认删除后自动同步，不再逐个上传确认。同步在应用层运行，不依赖打开 Skill 管理页。未登录仍可本地使用；系统 Skill 不上传。

采用账号绑定和基于已确认版本的双向合并：首次同步合并两端独有内容；一端修改自动同步到另一端；本地已确认删除传播为云端删除标记，云端删除仅在本地没有新修改时传播。两端冲突保留原内容并提示，不把“自动同步”解释为无条件覆盖。不同账号的个人 Skill 不交叉上传或覆盖。

编辑短暂防抖，未填完整的草稿不上传。同步串行合并触发，网络失败保留本地数据和幂等请求标识；下次登录、联网、修改或手动重试时继续，不无限轮询。迟到响应不能写入切换后的账号。

## 验证

已实现并验证，只使用模拟云请求，未同步真实个人数据。

- `src/features/skills/skillAutoSync.ts`：应用级同步服务，登录、恢复登录、联网恢复触发同步，编辑防抖 500ms；串行执行和账号会话代次检查；稳定 Skill ID、版本比较、幂等写入及删除标记。无后台无限重试或定时轮询。
- `src/App.vue`：在应用启动时初始化同步服务，切换页面不会停止同步。
- `SkillSyncPanel.vue`：移除逐个上传、下载副本的日常操作，显示自动同步状态、重试及冲突选择；冲突替换仍需确认，切换账号取消确认。
- `SkillManagementView.vue`：同步状态前置。保留“保存”作为显式本地保存入口，已登录时同步不依赖该按钮。
- 账号页和 README 更新数据说明；删除确认说明云端传播。此变更不上传服务器/凭据库/任务对象，Skill 正文仍需用户避免填写密码和密钥，服务端原有敏感内容检查保持不变。

身份及兼容说明：首次登录会关联本机未绑定的个人 Skill；旧手动同步记录用于恢复归属。退出后本地 Skill 不删除，但已绑定 Skill 不会自动上传到其他账号。多账号旧记录存在同 ID 冲突时不静默覆盖。原手动下载产生的独立副本保持为独立 ID，不通过名称推断它应替换哪一份云内容。

使用 `opsark.skillSyncOwners` 保存本地归属，`opsark.skillAutoSync.<userId>` 保存同步版本、内容比较基线与待确认的幂等标识；旧 `opsark.skillSync.<userId>` 不删除。基线缺失或两端都变化时保留冲突，不凭登录时间判断哪份是最新。客户端完整读取并验证云列表后才开始合并；系统 Skill 及来自其他账号的同 ID 不被覆盖。存储、网络或服务端限额错误会明确提示，保留可重试状态。
