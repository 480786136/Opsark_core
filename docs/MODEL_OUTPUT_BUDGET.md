# 自配模型输出预算

新增 DeepSeek、千问或其他自定义接入时，服务商输出上限默认未知。
“接入预算上限”留空表示未知，不以固定 16384 拒绝用户填写的生成预算。
按具体模型和接口文档填写上限后，前端和原生请求构造都会校验该上限。
未知输出上限不会确认 JSON/Schema、协议或高级参数能力，这些声明仍独立校验。

单模型生成预算覆盖全局规划预算；两者都留空时，单次请求默认使用 16384 Token。
已知接入上限更低时，默认预算随之降低。不会直接把更大的服务商上限用作请求预算。
官方模型继续采用平台声明的额度。任务/轮次总预算和自动恢复次数不变。

兼容迁移仅清除 `custom-unverified-v2`、来源 `unknown` 且值为 16384 的旧隐式上限；
明确声明的上限、其他数值、官方配置和用户填写的生成预算保持不变。
“恢复默认”高级参数仍保留单模型预算；要恢复预算继承，请清空“最大生成预算”。
